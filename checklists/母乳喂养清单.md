# 母乳喂养准备清单

目标医院：长沙市中心医院  
咨询门诊：门诊大楼 4 楼母乳喂养咨询门诊（公众号预约）  
住院时：直接找护士看含接，不要自己硬忍

## 孕 30–34 周：知识和家人

- [ ] 看完 [`08-母乳喂养准备.md`](../08-母乳喂养准备.md)
- [ ] 和配偶说好：头几天奶少也先勤含接，不擅自加糖水/米汤
- [ ] 把「不乱喂、先洗手」发到家庭群
- [ ] 产检时问：用药能否哺乳、乳头形态、咨询门诊怎么约
- [ ] 主陪护知道住院要请护士示范第一次含接和手挤奶

## 孕 32–36 周：物品

- [ ] 哺乳衣 / 前开扣待产裙 2–3 套
- [ ] 哺乳内衣 3–4 件
- [ ] 防溢乳垫
- [ ] 乳头舒缓膏
- [ ] 喂奶时垫靠的枕头（家用枕即可）
- [ ] 大容量带盖水杯
- [ ] 待产包里放 1 套哺乳衣、少量防溢垫、舒缓膏（入院用）

## 先不买，住院后再说

- [ ] 吸奶器（分离、严重涨奶、准备上班再买/租）
- [ ] 大量奶瓶
- [ ] 成箱奶粉
- [ ] 催奶茶、催奶汤包
- [ ] 乳盾、牵拉器（先经护士或咨询门诊）

## 住院期间

- [ ] 有条件皮肤接触，1 小时内尝试含接
- [ ] 请护士看第一次含接是否过深、有没有吞咽
- [ ] 学会手挤：乳晕变软再含
- [ ] 按需喂，不卡整点
- [ ] 乳头疼立刻叫护士，不硬喂
- [ ] 是否补配方奶只听医嘱，并问如何继续吸/含
- [ ] 问清出院后咨询门诊预约方式和复诊指征
- [ ] 宝宝去新生儿科时，问如何挤奶、送奶库

## 回家后 2 周

- [ ] 夜间继续喂，家人负责换尿布和递水
- [ ] 能说出每天大约几顿、湿尿裤大概几片
- [ ] 堵奶、红肿发热及时就医，不要自行回奶
- [ ] 体重、黄疸按儿保/出院医嘱复查
- [ ] 需要时预约 4 楼母乳喂养咨询门诊
