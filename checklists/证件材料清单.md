# 证件与报销材料清单

## 入院当天随身

- [ ] 产妇身份证原件
- [ ] 医保电子凭证 / 社保卡
- [ ] 诊疗卡
- [ ] 产检资料
- [ ] 住院证
- [ ] 预交款收据（办完入院后放入）

## 住院期间办理医保（按护士指引，通常入院 2 日内）

- [ ] 参保人员住院通知单（医生开）
- [ ] 身份证
- [ ] 住院证
- [ ] 医保手册或电子凭证

异地医保另备：

- [ ] 备案成功记录（住院前在参保地完成）

## 出院带走并拍照备份

- [ ] 住院发票
- [ ] 费用汇总清单
- [ ] 出院小结 / 出院诊断证明
- [ ] 医保结算单
- [ ] 新生儿疾病筛查、听力筛查回执
- [ ] 预防接种证或接种记录
- [ ] 出院带药说明书

## 出生医学证明

问医院窗口最新清单，常见包括：

- [ ] 父母身份证
- [ ] 结婚证
- [ ] 户口本
- [ ] 宝宝姓名
- [ ] 医院发的出生医学记录表

## 新生儿一件事 / 落户

线上「湘易办」常需：

- [ ] 父母身份证
- [ ] 户口本
- [ ] 结婚证
- [ ] 出生医学记录或已签发的出生证明

窗口办理以派出所为准，集体户口、父母不同民族等可能无法线上办。

## 新生儿医保

- [ ] 出生医学证明
- [ ] 父母一方湖南医保参保信息
- [ ] 湘医保「新生儿参保登记」提交成功截图

落户后：

- [ ] 办理参保信息变更

## 生育津贴（交给单位人事）

- [ ] 出生医学证明复印件
- [ ] 身份证复印件
- [ ] 出院小结 / 诊断证明（难产、剖宫产尤其需要）
- [ ] 医保结算单
- [ ] 本人银行卡号（津贴打个人账户）
- [ ] 单位要求的申领表签字

确认事项：

- [ ] 生育当月单位已缴纳生育保险到账
- [ ] 生育医疗费用已报销完成
- [ ] 单位网厅拨付对象选择「个人」

## 育儿补贴

- [ ] 出生医学证明
- [ ] 户口簿
- [ ] 申领人身份证
- [ ] 只通过微信/支付宝「育儿补贴」小程序或湘易办申请
