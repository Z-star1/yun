# 优先顺产准备清单

家庭意向：优先阴道分娩试产，安全第一，需要手术时配合医嘱。  
医院：长沙市中心医院

## 孕 30–36 周

- [ ] 在 [`templates/家庭档案.md`](../templates/家庭档案.md) 写明：分娩意向 = 优先顺产试产
- [ ] 看完 [`09-优先顺产计划.md`](../09-优先顺产计划.md)
- [ ] 产检问清：胎位、估重、有无试产禁忌
- [ ] 问无痛分娩、自由体位、家属陪产如何申请
- [ ] 和家人说好：不立「必须顺产」军令状，产房听医生
- [ ] 无禁忌时保持日常走路，体重按医嘱控制
- [ ] 主陪护知道：不擅自让产妇进食（可能随时手术）、不拦剖宫产签字

## 入院待产时告诉护士的三句话

- [ ] 「我们优先顺产试产。」
- [ ] 「希望评估后做无痛 / 暂缓无痛。」（二选一，提前想好）
- [ ] 「需要改手术请说明原因，我们配合。」

## 产房里

- [ ] 按时到院，不在家硬拖宫口
- [ ] 第一产程换体位、排尿、保存体力
- [ ] 无痛想做就早说，不要等疼到无法配合再提
- [ ] 开全后只在宫缩时按口令用力
- [ ] 侧切、产钳、剖宫产按当班医生判断
- [ ] 宝宝娩出后争取皮肤接触和早开奶

## 不要做

- [ ] 不到医院自行催产
- [ ] 亲友在产房外施压「再坚持、不许剖」
- [ ] 把无痛、侧切当成「没能真正顺产」
