# 待产包清单（表格，可发给家人）

目标医院：长沙市中心医院（南华大学附属长沙中心医院）  
地址：长沙市雨花区韶山南路 161 号  
建议完成日期：孕 36 周前封箱，放门口或后备箱（夜间也能 5 分钟拿走）

发给别人时优先用这两个文件（用手机/电脑直接打开或转发）：

| 文件 | 适合怎么发 |
| --- | --- |
| [待产包清单.xlsx](待产包清单.xlsx) | 微信、邮件发给会用 WPS / Excel 的人，可筛选、可打印 |
| [待产包清单.html](待产包清单.html) | 浏览器打开后打印成 PDF，或直接发文件；勾选列打印后用笔勾 |
| [待产包清单-入院.csv](待产包清单-入院.csv) | 备用纯表格，WPS 也能开 |
| [待产包清单-家里.csv](待产包清单-家里.csv) | 家里备货，不必搬进医院 |

原则：医院只带「证件 + 几天内用得上的」，家里再备「回来一个月要用的」。医疗决策以产科当面医嘱为准。
