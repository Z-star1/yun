# 待产包清单（勾选）

目标医院：长沙市中心医院  
建议完成日期：孕 36 周前  
放在：门口 / 后备箱（夜间也能拿走）

## 证件袋

- [ ] 产妇身份证
- [ ] 配偶身份证
- [ ] 医保电子凭证已登录 + 社保卡
- [ ] 医院诊疗卡
- [ ] 产检手册和所有报告
- [ ] 住院证（开了就放进去）
- [ ] 结婚证、户口本（办证时用，可后送）
- [ ] 银行卡、少量现金
- [ ] 血型 / 过敏 / 紧急联系人纸条

## 产妇

- [ ] 待产裙或哺乳衣 2–3 套
- [ ] 内裤 8–10 条
- [ ] 防滑拖鞋、袜子
- [ ] 薄外套
- [ ] 产妇卫生巾（日夜）
- [ ] 产褥垫 8–10 张
- [ ] 湿巾、纸巾、垃圾袋
- [ ] 洗漱用品、毛巾
- [ ] 带盖杯、吸管
- [ ] 充电器、充电宝
- [ ] 框架眼镜（如需要）
- [ ] 少量零食和饮水
- [ ] 会阴冲洗器（顺产，可入院后再补）
- [ ] 腹带（剖宫产，听医院意见）

## 宝宝（3–5 天用量）

- [ ] 连体衣 3–5 件
- [ ] 包被 / 包巾 2 条
- [ ] 帽子、袜子
- [ ] 纸尿裤（新生号码）1 包
- [ ] 隔尿垫
- [ ] 湿巾、柔纸巾

## 家属

- [ ] 身份证
- [ ] 换洗衣物、拖鞋、洗漱
- [ ] 充电宝、水杯
- [ ] 食堂/外卖支付方式

## 不要带

- [ ] 热得快、电煮锅
- [ ] 大量奶粉奶瓶（先按医院喂养指导）
- [ ] 贵重首饰、大量现金
- [ ] 过多换季衣物
